# Lilt

My custom, minimal fork of [Kaset](https://github.com/sozercan/kaset), a native macOS client for YouTube Music.

## Build

```bash
Scripts/build-app.sh release
ditto .build/app/Lilt.app /Applications/Lilt.app
```
